# Компонент языка SM-06

Здесь лежит учебная реализация выбора языка и пять авторских пакетов. Каталог не даёт права на рассылку, доступ к рабочей базе или живому callback сохранения.

`first_sm06_language.py` делает две вещи:

1. `select_language` выбирает локаль по уже нормализованным свидетельствам. Порядок такой: явное предпочтение получателя, язык содержательного ответа, проверенный деловой язык компании, затем `en-GB`. Неподдержанный явный выбор не заменяется следующим свидетельством и не заменяется английским.
2. `prepare_language_materials` передаёт выбранную локаль в настоящий `prepare_bound_materials` (F130). Текст не переводится и не нормализуется. Закреплённая версия пакета используется так, как её передал вызывающий код.

Пакеты `packs/en-GB.json`, `ru-RU.json`, `es-ES.json`, `da-DK.json` и `uk-UA.json` — образцы `FIRST_LANGUAGE_PACK_V1`. В каждом пять шаблонов: `initial`, `question`, `objection`, `followup`, `handoff`. Это не рабочая коммерческая база. Старые reference-пакеты EN/RU остаются в `reference/` и этим каталогом не заменяются.

Проверка из корня пакета:

```text
python -B PACKAGE_CHECK.py
python -B acceptance/run.py cp0
python -B acceptance/run.py cp1
```

`cp0` гоняет прежние зависимости. `cp1` гоняет замороженную приёмку SM-06 и тесты из `candidate/tests`. Callback в тестах хранит результат в памяти. К worker, Make, очереди и отправке его подключать не нужно.

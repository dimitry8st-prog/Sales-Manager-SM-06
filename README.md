# Sales Manager FIRST — SM-06 R1

Компонент выбора языка по доверенным нормализованным свидетельствам и подготовки точных материалов через принятый F130.

**Компонентный возврат готов к независимой приёмке.** Полный runtime SM-06 и производственное подключение этой работой не закрываются.

## Результат

- Язык выбирается по приоритету: явное предпочтение получателя → язык содержательного ответа → подтверждённый деловой язык компании → `en-GB`, если все три свидетельства отсутствуют.
- Явно выбранная недоступная локаль вызывает ошибку; понижения приоритета и замены английским нет.
- Подготовка использует настоящий F105/F106/F120/F122/F130, сохраняет точные тексты, ошибки и результат callback; без перевода, повторного сохранения и отправки.
- Поставляются пять NONPROD authoring-пакетов: **en-GB, ru-RU, es-ES, da-DK, uk-UA**. В каждом initial/question/objection/followup/handoff; всего 25 шаблонов.
- Существующие EN/RU reference и все 55 защищённых файлов сохранены.

## Воспроизведение

После распаковки возврата с Python 3.12:

```sh
cd SM06_Dmitry_R1
python -B PACKAGE_CHECK.py
python -B acceptance/run.py cp0
python -B acceptance/run.py cp1
```

Из checkout этого репозитория, включая сохранённый исходный ZIP, можно повторить два чистых прогона и пересобрать возврат:

```sh
python -B SM06_Dmitry_R1/return/verify_sm06.py --repo .
```

Скрипт перезаписывает только результаты в `return/` и `artifacts/`; исходный ZIP и protected source не изменяет. Новые временные пути/время/commit закономерно изменят хеш вновь собранного архива.
